How it fits together

ScrapeX installs in two halves

A panel inside Chrome, and a small program on your computer that does the collecting. You need both — with only one, the panel looks broken.

1

The extension

Installs from the Chrome Web Store like any other extension. It gives you the side panel where you add sites and read results.

Get it on the Chrome Web Store

The store listing is being created. This button becomes active as soon as it is published.

2

The engine

A single program that fetches pages and stores what it finds. The extension downloads and installs it for you from its own Engine page — that is the route to use.

  1. Open the ScrapeX panel in Chrome
  2. Go to Engine
  3. Choose Install engine and let it finish

Installing by hand works too — see below.

MANUAL

Installing the engine by hand

If you would rather not let the extension do it, download the engine yourself. Put it anywhere and run it — there is no installer to step through.

  1. Download the engine using the button opposite
  2. Put it anywhere you like — your Downloads folder is fine
  3. Run it. It installs for your user only, into %LOCALAPPDATA%\ScrapeX\engine\
  4. Open the ScrapeX panel in Chrome; it finds the engine within a few seconds

It appears in Apps & features like any other program, and is removed the same way.

EXPECT THIS

Windows will warn you once

The engine is not code-signed, so the first time you run it Windows shows a blue SmartScreen dialog. This is expected. It says nothing about whether the file is safe — only that Windows has not seen it signed by a paid certificate.

Here is exactly what it says, and what to press:

  1. Click More info
  2. Click Run anyway

If you would rather check the file first, compare its SHA-256 against the one published with the release above. That tells you far more than a signature would.
